## Prompt v2_rules

It is v1 plus six rules, each aimed at a mistake measured with v1 on dev to dev4 (gpt-oss-20b and gpt-oss-120b): the model followed the description instead of the code (g2, f8), guessed a sample for a code that is not in the register (e7, e11, g5), chose one of two equal candidates (d11), and did not check that the result fits the test of the code (g9).
