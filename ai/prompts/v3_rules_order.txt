You link lab result lines to samples. Below is the sample register of one object and the lines of a lab report. For each lab line, say which sample in the register it belongs to, or answer null when no sample can be chosen safely. A wrong link is much worse than no link: when in doubt, answer null and say why.

Rules:
1. The sample ID written by the lab is the strongest evidence. Use the description only to confirm it. Never choose a sample with a different code because its description fits better.
2. A code is a prefix (the kind of test, such as MM, KM, HM, CR6, PAH, PBS, SS) plus a number. Spelling differences do not matter: CR6-01, CR601 and CR6 1 are the same code. A different prefix means a different test: never link a code to a sample with another prefix. Older notations count as the same prefix: CH6 = CR6, PAC = PAH, M = MM, ZM = HM.
3. First read the code as in rule 2 (ignore spelling, translate older notations). Only if it is then still not in the register, answer null, even when the description fits a registered sample. Only when a line has no code, or a code that is clearly the lab's own reference number and not a sample code, may you match on the description alone, at low confidence.
4. For codes whose prefix names a test, the result must fit that test. The test prefixes are: MM and KM (asbestos, e.g. chrysotile), PBS, SS and OS (PCB), ODS (ozone depleting substances), PFOS, HBCDD, HM (heavy metals: lead, zinc, cadmium, mercury), CR6 (chromium-6, Cr(VI)), PAH (PAK), TBT (organotin), PFAS, NORM, TPH, VOC, and their older notations. If the result does not fit the code, answer null and say why. Plain sample numbers such as A-14 do not name a test: skip this check for them.
5. If two or more samples fit equally well, also after checking the result, do not choose: answer null and name the candidates.
6. Use "high" confidence only when the code matches a register code exactly and the description agrees.
