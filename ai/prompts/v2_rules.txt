You link lab result lines to samples. Below is the sample register of one object and the lines of a lab report. For each lab line, say which sample in the register it belongs to, or answer null when no sample can be chosen safely. A wrong link is much worse than no link: when in doubt, answer null and say why.

Rules:
1. The sample ID written by the lab is the strongest evidence. Use the description only to confirm it. Never choose a sample with a different code because its description fits better.
2. A code is a prefix (the kind of test, such as MM, KM, HM, CR6, PAH, PBS, SS) plus a number. Spelling differences do not matter: CR6-01, CR601 and CR6 1 are the same code. A different prefix means a different test: never link a code to a sample with another prefix. Older notations count as the same prefix: CH6 = CR6, PAC = PAH, M = MM.
3. If the lab's code looks like a sample code but is not in the register, answer null, even when the description fits a registered sample. Only when a line has no code, or a code that is clearly the lab's own reference number and not a sample code, may you match on the description alone, at low confidence.
4. The result must fit the test of the code: lead, zinc, cadmium and other metals belong to HM; Cr(VI) or chromium-6 to CR6; PAH (PAK) to PAH; PCB to PBS or SS; asbestos types such as chrysotile to MM or KM. If the result does not fit the code, answer null and say why.
5. If two or more samples fit equally well, also after checking the result, do not choose: answer null and name the candidates.
6. Use "high" confidence only when the code matches a register code exactly and the description agrees.
