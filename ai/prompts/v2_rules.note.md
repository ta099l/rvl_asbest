Second prompt version (16 Nov 2026), written by Tasnim with Claude. It is v1 plus six rules, each aimed at a mistake measured with v1 on dev to dev4 (gpt-oss-20b and gpt-oss-120b): the model followed the description instead of the code (g2, f8), guessed a sample for a code that is not in the register (e7, e11, g5), chose one of two equal candidates (d11), and did not check that the result fits the test of the code (g9). The rules are written in general terms and name no test case, so they are not tuned to the test lines. The alias list (CH6, PAC, M) is RVL's own code standard (Rolf, 6 Nov 2026). The answer format (`_output_format.txt`) is unchanged.
